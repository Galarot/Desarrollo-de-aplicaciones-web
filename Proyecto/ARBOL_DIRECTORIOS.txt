🌍 RUTAS PRINCIPALES DISPONIBLES:

  GET  /                → Página principal (juego clásico)
  GET  /artcart         → Modo Art Cart

  GET  /api/splash      → API JSON de artes


═══════════════════════════════════════════════════════════════════════════════

⭐ ARCHIVOS CRÍTICOS A CONOCER:

  1. bin/console              → CLI de Symfony (ejecutar comandos)
  2. public/index.php         → Punto de entrada (siempre)
  3. src/Controller/DBLegendleController.php → Lógica principal
  4. templates/db_legendle/   → Vistas (Twig)
  5. config/packages/         → Configuración
  6. data/                    → Datos JSON
  7. public/assets/           → Imágenes
  8. composer.json            → Dependencias


═══════════════════════════════════════════════════════════════════════════════

🚀 COMANDOS IMPORTANTES:

  composer install              ← Instalar dependencias (primero!)
  php bin/console cache:clear   ← Limpiar caché
  php -S localhost:8000 -t public/  ← Ejecutar servidor
  php bin/console debug:router  ← Ver rutas
  php bin/console debug:container ← Ver servicios
