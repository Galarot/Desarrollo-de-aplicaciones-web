🔧 SI TIENES PROBLEMAS

"Command 'php' not found"
  → Instala PHP desde https://www.php.net/downloads
  → O usa tu sistema operativo:
     - Windows: descarga directamente
     - Mac: brew install php
     - Linux: apt-get install php

"Composer not found"
  → Instala Composer desde https://getcomposer.org/download/

"Error en install.bat"
  → Ejecuta manualmente:
     composer install
     php bin/console cache:clear

"Las imágenes no cargan"
  → Verifica que estén en: public/assets/
  → Revisa que el servidor use public/ como root
